# NickMobus.github.io

Personal project hub for Nick Mobus. The homepage renders a grid of projects
from [`projects.json`](projects.json) — machine learning, data analysis, and
other computational work, some hosted here and some linking out to other
repos.

Plain HTML/CSS/JS, no build step or framework.

- `index.html` — homepage
- `assets/` — site CSS and JS
- `projects.json` — single source of truth for the project grid
- `projects/` — projects hosted directly in this repo (e.g.
  `projects/ocean-acidification/`, a machine learning course project on
  predicting ocean acidification from atmospheric CO2)

See [`HOW_TO_ADD_A_PROJECT.md`](HOW_TO_ADD_A_PROJECT.md) for adding new
entries to the grid.
